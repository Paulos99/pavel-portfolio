# pavel-portfolio

Одностраничное портфолио Павла Анцибора.

**Live:** https://paulos99.github.io/pavel-portfolio/

Светлый editorial one-pager: hero, типы задач, готовые кейсы, in progress, процесс, контакт.

## Стек

Статика: `index.html` + `css/styles.css` + `js/main.js`. GitHub Pages с ветки `main`, корень.

## Контент

Готовые кейсы (с живого pavel-web-services):

- MultiFrame — https://stp-multiframe.ru/calc/
- ТРИЗ — https://paulos99.github.io/TRIZ/
- ЦИА — https://paulos99.github.io/cia-room/

In progress: ЦИА, MultiFrame/StP, STP, Эславия.

## Правки

Редактируйте HTML/CSS/JS и пушьте в `main`. Не копировать секреты Telegram-бота с каталога услуг.
